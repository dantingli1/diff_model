# GLGait SUSTech1K E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在原生 GLGait 中增加可由 RGB 端到端训练和测试的 SUSTech1K 模型。

**Architecture:** `E2EGLGait` 继承 `Baseline_trans`，前置双解码 U-Net 预测 P/T，经可微二值化和 ROI 对齐生成 `64×44` mask，再调用原 GLGait forward。训练增加 P/T 加权 Smooth L1，测试只读取 ratio 与 RGB。

**Tech Stack:** Python 3.10、PyTorch、torchvision ROI Align、OpenGait 原生训练框架、YAML、unittest。

## Global Constraints

- 所有测试使用 gait0。
- 保留现有脏工作区，不纳入无关修改。
- SUSTech1K 训练模态固定为索引 `[4,5,7,17]`，评估固定为 `[4,5]`。
- RGB raw 使用 NHWC→NCHW 转换，识别输入固定为 `64×44`。
- 不加入定期图片导出、动态 decoder 冻结或额外消融开关。
